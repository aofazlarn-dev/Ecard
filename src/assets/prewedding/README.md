# ใส่ภาพ Pre-wedding ที่นี่

วางรูป JPG, JPEG, PNG, WebP หรือ AVIF ในโฟลเดอร์นี้โดยตรง (ไม่ต้องสร้างโฟลเดอร์ย่อย)
ตั้งชื่อ `01.jpg`, `02.jpg`, `03.webp` เพื่อกำหนดลำดับ เว็บจะค้นหารูปและเรียงตามชื่ออัตโนมัติ

แนะนำความกว้างประมาณ 1,600–2,000 px และขนาดไม่เกินประมาณ 500 KB ต่อรูป เพื่อให้โหลดบนมือถือได้เร็ว
รูปต้นฉบับสามารถเก็บแยกไว้ได้ หน้าแกลเลอรีจะครอบภาพตัวอย่างให้สวยงาม แต่หน้าขยายแสดงรูปเต็มโดยไม่ตัดขอบ

เมื่อเพิ่ม/ลบรูปแล้ว ให้ build และเผยแพร่เว็บใหม่ (GitHub Actions จะทำให้เมื่อ push ไป main)
หาก dev server ในเครื่องไม่เห็นไฟล์ที่เพิ่ม ให้เริ่ม dev server ใหม่
การใส่ไฟล์นี้ไม่ใช่การอัปโหลดผ่านแอดมิน และไม่ใช้พื้นที่ฐานข้อมูล Supabase

ระหว่างที่ยังไม่มีรูป เว็บไซต์จะแสดงข้อความ “ความทรงจำของเรา…เร็ว ๆ นี้” โดยไม่ใช้ภาพสมมติแทนภาพจริง
